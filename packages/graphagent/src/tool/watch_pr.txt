Register, query, or cancel a durable watch for a GitHub pull request or GitLab merge request. `register` needs a full request URL (for example https://github.com/owner/repo/pull/123 or https://gitlab.com/group/project/-/merge_requests/123) and returns a watch ID (a StateRef); a process-level poller watches the forge outside this turn. `query` shows one watch by ID or URL, or lists this session's live watches. `cancel` stops a live watch.

A watch notice is delivered into this session at a turn boundary — after the current turn ends — and reports checks settling, the request merging or closing, a review-state change, or the deadline. A pushed head rebaselines the watch silently, so one watch follows the request across pushes. The default deadline is 1800 seconds. A self-hosted GitHub or GitLab host must be added to the comma-separated GRAPHAGENT_WATCH_PR_HOSTS environment variable. A root session's successful `gh pr create` registers a watch automatically; use `register` for a request created another way. An autonomous goal can wait on a watch with goal action=intent intent=await wait_source=watch_pr and wait_id set to the watch ID or the request URL. This tool never pushes, merges, or changes platform state. The watch ID marks registration, not evidence: query the current head and its checks before reporting status or merging. Do not sleep or poll in the foreground.
