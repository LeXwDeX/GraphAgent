Delegate a self-contained task to a subagent. Use this for broad, open-ended exploration or work that needs several rounds of searching; use read, glob, or grep directly for a specific file, symbol, or small set of files.

- Specify subagent_type from the available agent types. Respect inherited permissions and the shared `maxToolCalls` budget.
- Give each agent all needed context: a new agent starts fresh and does not see this conversation. State whether it should write code or research, and include verification steps.
- Launch independent agents concurrently in one message. Do not repeat a delegated task; wait or continue other work. Background execution, when enabled, notifies you on completion.
- The agent returns one message that the user cannot see; summarize it. Check key claims, such as changed files or test results, before relying on or reporting them.
- Pass task_id to resume a previous session with its history.
