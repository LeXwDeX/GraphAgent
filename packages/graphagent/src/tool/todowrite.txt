Maintain a todo list for multi-step work. Use this when a task has 3+ distinct steps, when the user supplies several tasks, or when progress would otherwise be hard to follow; skip it for questions and single edits.

- States: pending, in_progress, completed, cancelled. Keep exactly one in_progress while work remains.
- Update status in real time. Mark completed only after the work and its verification are actually done, never on intent.
- Keep items specific and actionable; preserve user-provided commands verbatim; add follow-ups for new work or a blocker.
