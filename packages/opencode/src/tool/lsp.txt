Query language servers for code intelligence. Use this for definitions, references, symbols, hover, implementations, and call hierarchies; use grep or glob for text search.

Operations: goToDefinition, findReferences, hover, documentSymbol, workspaceSymbol (also takes query), goToImplementation, prepareCallHierarchy, incomingCalls, outgoingCalls.

All operations require filePath, line, and character (both 1-based). The file type needs a configured LSP server, or the call fails.
