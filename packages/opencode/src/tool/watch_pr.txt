Start a read-only background watch for a GitHub pull request or GitLab merge request. Pass a full request URL (for example https://github.com/owner/repo/pull/123 or https://gitlab.com/group/project/-/merge_requests/123). The tool returns a job ID immediately and delivers exactly one completion notice into this session when checks settle, the request merges or closes, the review state changes, the head changes, the deadline expires, or the forge CLI is unavailable.

The watch polls the forge CLI (gh for GitHub, glab for GitLab) for the head observed at start. A new head is a new watch. The default deadline is 1800 seconds and the default poll interval is 15 seconds; both can be set per call. A self-hosted GitHub or GitLab host must be added to the comma-separated GRAPHAGENT_WATCH_PR_HOSTS environment variable. This tool never pushes, merges, or changes platform state. A notice marks delivery, not authority: query the current head and its checks before reporting status or merging. Do not sleep or poll in the foreground while the watch runs; continue with other work.
