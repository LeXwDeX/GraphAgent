Search file contents with a regular expression. Use this to locate code by pattern or text; use glob to find filenames and read for a known file.

- Patterns use full regex syntax, for example "log.*Error" or "function\s+\w+".
- include filters paths, for example "*.js" or "*.{ts,tsx}".
- Returns file paths, line numbers, and matching lines, at most 100; a truncation notice appears when more exist. An empty search returns "No files found".
- For match counts, run `rg --count` with the shell tool. For open-ended searches that need several rounds, delegate with task instead.
