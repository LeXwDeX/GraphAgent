# GraphAgent 功能与源码索引

本文是功能与源码入口索引，不是完整的 OpenCode 上游差异报告。功能归属按 GraphAgent 产品划分，不定义版权或许可范围，许可边界以 [`NOTICE`](../NOTICE) 和 [`LICENSE-UPSTREAM.txt`](../LICENSE-UPSTREAM.txt) 为准。行为细节以 [中文 README](../README.md)、对应实现和测试为准。

## 既有能力的增强

| 能力                                 | 增强                                                                                                                                                                                                                                                                                                           | 源码                                                                                                                                                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 思考自动塑形（默认关闭，需显式开启） | 后台整理已结束的普通思考，构建请求时采用已完成改写；仅在更省 token 时采用，原文可回放；详见 [README](../README.md#思考塑形)。                                                                                                                                                                           | [`packages/core/src/session/reasoning-distillation/`](../packages/core/src/session/reasoning-distillation/)                                                                                          |
| 上下文管理                           | 通用工具输出受 `tool_output.max_lines`、`tool_output.max_bytes` 限制，`read`、`grep`、`glob`、`shell` 使用各自预算；`maxToolCalls` 限制调用次数；每次截断都给出可执行的续读方式；长会话压缩沿用 GraphAgent 配置；上下文折叠为遗留能力，默认关闭，仅在显式开启时生效；详见 [README](../README.md#上下文管理)。 | [`packages/core/src/session/tool-budget.ts`](../packages/core/src/session/tool-budget.ts)、[`packages/graphagent/src/tool/truncate.ts`](../packages/graphagent/src/tool/truncate.ts)                 |
| 子智能体委派                         | `task` 支持按 `task_id` 继续；后台子智能体完成通知受实验开关控制；详见 [README](../README.md#其他改动)。                                                                                                                                                                                                             | [`packages/graphagent/src/tool/task.ts`](../packages/graphagent/src/tool/task.ts)                                                                                                                    |
| OpenAI Responses 传输                | 自定义 `@ai-sdk/openai` Provider 可选 WebSocket，保留 HTTP/SSE 回退；详见 [说明](../packages/graphagent/src/plugin/openai/README.md)。                                                                                                                                                                         | [`packages/graphagent/src/plugin/openai/README.md`](../packages/graphagent/src/plugin/openai/README.md)                                                                                              |
| 工具与终端健壮性                     | 工具自描述与严格 `edit` 匹配（歧义候选列出行号，找不到时给出最近片段）；截断输出带续读方式；工具参数校验、Unicode 转义与子进程边界修复；详见 [README](../README.md#其他改动)。                                                                            | [`packages/graphagent/src/tool/`](../packages/graphagent/src/tool/)、[`packages/tui/src/`](../packages/tui/src/)                                                                                     |
| 统一系统提示词                       | 所有模型共用同一份系统提示词（身份、hooks 与 DAG 入口、工作规则、安全约束）；工具用法由工具自描述承载，常驻 DAG 与 hooks 指导保持入口形态，详见 [README](../README.md#其他改动)。                                                                                                                 | [`packages/graphagent/src/session/system.ts`](../packages/graphagent/src/session/system.ts)、[`packages/core/src/system-context/graphagent.txt`](../packages/core/src/system-context/graphagent.txt) |
| Provider 请求重试                    | 所有 4xx/5xx 与网络失败共用一套指数退避和一张分发表：`429`/`503` 遵守 `retry-after`，`401`/`403` 做一次凭据刷新，`413`/上下文溢出转交压缩，终止失败不重试；被闸门或上限挡住时记录 `retry stopped`；详见 [compaction-retry](./compaction-retry.md#provider-retry-dispatch)。                                    | [`packages/graphagent/src/session/retry.ts`](../packages/graphagent/src/session/retry.ts)                                                                                                            |
| 工作目录管理                         | 支持使用独立 `git worktree` 管理工作目录；工作流不会自动隔离，并发工作流须使用不同 worktree，或串行执行。                                                                                                                                                                                                      | [`packages/graphagent/src/worktree/`](../packages/graphagent/src/worktree/)、[DAG 并发边界](../packages/graphagent/src/dag/CONTEXT.md)                                                               |
